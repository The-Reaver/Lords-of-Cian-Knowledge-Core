# The Case They Never Touched

*Locked canon, Batch 267, 2026-09-11 (`MCD-1399`). Industrial Myth Alias Chronicle XCIII, wave 31, closing the wave. The method's first fully solo case run start to finish by a trained district auditor, with Kanja and Ezio absent from every stage of it.*

---

The report reached them four weeks after the case had already closed — a finished finding, properly cross-referenced, properly posted, the settlement already paid and the district auditor who'd run it already moved on to the next complaint on her own list. Neither Kanja nor Ezio had set foot in the district. Neither had been asked to.

Ezio read the report twice, the way he read everything, looking for the seam where it would fall apart under scrutiny the way the mining district's incomplete secondhand version once nearly had. He didn't find one. The testimony was cross-referenced against three independent sources exactly the way the standard called for. The arithmetic held. The finding was posted, dated, and signed in a hand that wasn't his own and had never needed to be.

"We trained her eighteen months ago," Ezio said. "One case, alongside us, to see how she worked. This is the first one she's run entirely without either of us within a hundred miles of it."

"How does it read to you? Not as a compliment. As an audit."

Ezio turned back to the first page and read it again, slower, the way he'd have read a case built by a hostile administrator looking for the flaw that would let it fall. "It reads like ours. Not a copy of ours — ours. Same discipline, same refusal to round a number toward what would be easier to hear, same honesty about the one figure she couldn't fully verify and flagged as provisional rather than guess at."

"Then it is ours. It just isn't only ours anymore." Kanja set the report down beside the eleven volumes it would eventually be copied into, not the first case run without him in the room and, both of them understood without saying it, very likely not the last. What unsettled him wasn't the distance — it was recognizing that the method's real test had never been whether he and Ezio could run it well. It was whether it still ran the same way when neither of them was there to make sure it did.

"Next case," Ezio said, "might be one we never even hear about until it's already closed."

"Then it'll still be true when we finally do. That was always the only part that had to stay ours."
