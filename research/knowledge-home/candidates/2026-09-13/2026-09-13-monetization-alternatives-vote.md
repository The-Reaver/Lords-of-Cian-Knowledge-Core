## Body
The Brain Trust put seven distinct monetization models to a vote, none dropped without a
result recorded:

| Model | Description | Result |
|---|---|---|
| A | $1/$2/$3 as stated, on clearance_level, simultaneous launch | Unanimous HOLD (6/6) -- rejected |
| B | Same prices, decoupled entitlement schema | Plurality SHIP WITH CONDITIONS (3/6) -- no majority |
| C | Drop $1, one validated tier + annual, sequential rollout | Majority SHIP WITH CONDITIONS (4/6) |
| D | Keep 3 tiers, $1 cosmetic-only, gating starts at $2 | Plurality SHIP (3/6) -- no majority |
| E | Add a one-time "unlock forever" purchase alongside subscriptions | Plurality HOLD (3/6) -- did not carry |
| F | Replace the 100k target with a staged conversion-rate metric ladder | Majority SHIP (4/6) -- strongest consensus on the slate |
| G | Pay-what-you-want, $1 floor, no fixed SKUs | Dead 3-3 tie -- genuine deadlock |

AJ's independent 4-Breaker audit, working from the opposite direction (breaking the original
proposal rather than designing alternatives), converged on essentially Models D+E combined:
separate "access" from "support" -- a cheap ongoing supporter tier for perks only that never
gates content, plus a per-content one-time unlock for real access. The carried recommendation
(2026-09-13-monetization-carried-recommendation.md) draws on C, D+E, and F.

Model G (pay-what-you-want) was never voted down -- it is a live, unresolved option if Abad
wants it reconsidered, not a rejected one.
