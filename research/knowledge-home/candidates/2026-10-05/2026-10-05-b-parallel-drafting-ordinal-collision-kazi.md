# Parallel drafting caused Kazi's Femi-arc entries to claim the same ordinal positions as Tunji's entries

## Body
Two parallel agents each drafted a five-Chronicle run continuing Kazi's series (Tunji's IV-VIII and Femi's IX-XIII). Femi's entries (MCD-1528 to MCD-1532) wrongly described themselves as the fourth through eighth Kazi Chronicles, duplicating Tunji's own correct claim. Batch 338 fixed the ordinal statements. The same Detroit pass amended MCD-472 to remove a world-bleed error and corrected a floor-size number conflation (200 workers versus 4,000 pamphlet readers). Lesson: when disjoint runs of one series are drafted in parallel, the ordinal wording must be assigned centrally up front, not inferred by each agent from the existing count.
