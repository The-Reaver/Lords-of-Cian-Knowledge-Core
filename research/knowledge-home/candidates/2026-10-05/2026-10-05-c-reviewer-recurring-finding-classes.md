## Body
Recurring finding classes from the independent review rounds of this span. (1) Unlabeled new facts: a proposal that quietly introduces a fact not held by any locked rule without marking it 'a new fact' with its home rule; the Pyro and Triad profiles now mark each such fact explicitly ('New fact:', 'a new fact', 'Home:'). (2) Costs listed under one option only: a cost that applies to several options stated for one, so the options look unequal; the profiles now write 'Under every option, ...' and 'Under options 2 and 3, cost: ...' paragraphs. (3) Leaning 'no recommendation' items: an item presented without a recommended answer, which forces the author to start from nothing; every item on the approval list now carries a recommendation and one alternative. (4) Double-assigned findings: the same finding assigned to two places so it is resolved twice or neither; the profiles now name a single home rule or file for each coordinated amendment. Practical use: before sending a draft to review, check these four classes first, since each round spent on one of them delays the gate.
