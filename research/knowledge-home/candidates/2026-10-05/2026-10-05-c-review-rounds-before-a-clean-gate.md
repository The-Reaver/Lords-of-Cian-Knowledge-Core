## Body
Round counts recorded in the Batch 369-375 notes. Cosmology (Batch 369): an independent adversarial review found five critical gaps (missed orbital-trade wording, the Foreign Sea nation's routine traffic, the Living Drakma range, two-way Kares Prime traffic, the homage-to-Cian route), all fixed before lock. Anirak's Combination Codex (Batch 370): four reviews, NOT CLEAN three times. Anirak's profile rules (Batch 371): six independent reviews, five NOT CLEAN; Foreclosure's original wording contradicted the approved kill register and the rest was stale doc text. Anirak's first wave (Batch 373): Chronicle I five review rounds, II six, III four, each fixed and re-reviewed until clean, after which each took only small optional wording edits that add no facts. Series names and account types (Batch 375): seventeen independent reviews, ending with a re-presentation to the author; the eighth review found approval item 39. Lessons: a fix applied after one review can create the next review's finding, so re-review after every fix; a clean verdict is the exit condition, not a round count; and a late review can still surface a new conflict, so the gate is run to clean rather than for a fixed number of passes. The author's own rule for the Codex was that without a clean review it 'NEVER passes'.
